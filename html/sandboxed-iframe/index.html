Sandboxed iframe (the Proton Mail pattern)

This replicates what broke Proton Mail in Firefox (issue #99): The “email” is rendered into a sandboxed about:blank iframe without allow-scripts. Listeners are attached to the iframe’s body (like Proton’s useIframeDispatchEvents). “Switching email” removes the iframe from the DOM, and a deferred cleanup (like React’s passive effect cleanup) calls removeEventListener on the old body.

With the bug present, the cleanup throws TypeError: can't access dead object in Firefox, because the hooked removeEventListener died together with the removed frame’s content script sandbox.
